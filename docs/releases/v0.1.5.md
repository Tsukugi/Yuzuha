## User-facing change

Home now has a Settings action. Settings contains an Appearance disclosure and
an expanded Android Code updates disclosure. The user can check GitHub
Releases, download a newer verified bundle, and reopen Yuzuha to apply it.
Data tools keeps the same update control collapsed as a secondary path.

The update stays native-owned: JavaScript calls the typed bridge and never
downloads, hashes, verifies, or activates executable code. Native app changes
still require an APK.
