## Changes

- Periodic money operations use the normal Money form with one Repeat toggle.
- Daily operations expose a compact Mon–Sun weekday toggle row; only selected weekdays are applied.
- The user no longer enters a first date. New periodic operations use today as their internal start date.
- The repeat panel uses tighter padding and no new schema, network request, worker, timer, or polling loop.
- The current latest-only boundary remains app schema 33 and repository schema 3.
