## User-facing change

The shared UI standardization pass keeps primary capture controls visible and
places optional controls behind labeled disclosures. In Money, a single active
account is assigned automatically, so new money and split-entry forms do not
show a redundant account selector. Money history and report account filters
also stay hidden when there is only one active account. Account choices remain
available when multiple active accounts exist; transfers keep source and target
choices because they require two different accounts.
