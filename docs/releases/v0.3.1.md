# Yuzuha 0.3.1

Compatible patch for native 0.3.0; Android version code 10. Release in preparation.

YZ-027 restores floating add buttons on Home, Money, Notes and Tasks. The list
fills the viewport behind the button instead of losing an 88 dp reserved row.
Scroll-end clearance keeps the final item accessible. Home quick capture stays
above the FAB; money form Save/Cancel retain their keyboard-safe row.

No native API, dependency, schema, migration or installer algorithm change.
Package/embedded version is 0.3.1; native baseline stays 0.3.0. Existing native
0.3.x receives OTA; older lines use the complete signed APK. Preserve the legacy
0.1.11 bundle.json and 0.2.1 bundle-0.2.json pointers unchanged.

Pre-release UI validation: 65 suites / 327 tests, typecheck, lint and localTest
build passed. API 35 emulator at 320×640 dp shows content behind the FAB,
quick capture opening/Back dismissal and the final Home card reachable.
Money, Notes and Tasks list captures are also saved. See
[UI evidence and limits](../fab-overlay-2026-10-30.md).
