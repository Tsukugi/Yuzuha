# Yuzuha OTA v0.1.6

Status: Published on 2026-08-08 as the final Android JavaScript OTA release
for the Settings view.

## Release identity

- Source commit: `a889875`.
- Native compatibility baseline: `0.1.3`.
- Runtime: React Native `0.86.0`.
- GitHub Release: [Tsukugi/Yuzuha OTA v0.1.6](https://github.com/Tsukugi/Yuzuha/releases/tag/v0.1.6).
- Metadata: [`bundle.json`](https://github.com/Tsukugi/Yuzuha/releases/download/v0.1.6/bundle.json).
- Bundle: [`Yuzuha-0.1.6.jsbundle`](https://github.com/Tsukugi/Yuzuha/releases/download/v0.1.6/Yuzuha-0.1.6.jsbundle).
- Bundle size: `1,322,538` bytes.
- Bundle SHA-256: `ae8d3a335bb501feaf83271f60ad84c53d60f0f80f75dbdb2928f66dd38787ae`.

## User-facing change

- Home has a visible Settings action and a secondary Open settings action.
- Settings owns the Appearance disclosure.
- Settings opens Android Code updates by default and exposes `Check for
  updates`, available-version, download, prepared, current, and error states.
- Data tools keeps the same native-backed update control collapsed as a
  secondary path.

## Release boundary

This OTA keeps app schema 33 and repository schema 3. It adds no native module,
permission, migration, worker, timer, or background update service.
