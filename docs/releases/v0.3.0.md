# Yuzuha 0.3.0

Native baseline release; Android version code 9. Publication is being prepared.

The app keeps primary capture and current values visible, with secondary
configuration and continuations opened on request. Shared labeled action icons,
Android Back/draft handling, visible restore errors, periodic capture defaults,
permission refresh and keyboard-safe money actions are included (YZ-018–YZ-025).
The prior Settings/Paper and date-format passes are included in the source commit.

## Compatibility

The icon font and native icon library require a new APK for native 0.2.x.
Release preflight rejected the original dynamic font import as an unsupported
Metro asset. Metro now selects the library's static icon entry, using the font
bundled in the APK. A regression test verifies icon and ordinary module resolution.
The OTA remains one signed JavaScript file with no external Metro assets.

Version 0.3.0 starts native line 0.3; its same-version signed bundle is an
explicit embedded baseline, not an OTA for native 0.2.x. Older native 0.2.x
shells use their signed cross-line APK updater. Native 0.1.3 still needs manual
bootstrap. Preserve bundle.json (0.1.11) and bundle-0.2.json (0.2.1) byte for byte;
add bundle-0.3.json and point android-update.json to the complete 0.3.0 APK.

No schema migration or workspace reset is introduced. Existing schema 33 and
repository schema 3 boundaries remain. Android API 33 minimum and React Native
0.86.0 / React 19.2.8 are unchanged. UI evidence from the previous localTest
build is linked in the usability reports; release-specific verification follows.
